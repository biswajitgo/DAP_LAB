Virat Kohli Centuries Data Analysis

A data analytics project based on Virat Kohli's international centuries using Python, Pandas, Matplotlib, and Seaborn.
This project performs data cleaning, statistical analysis, and visualization to discover insights from Virat Kohli’s century records across different cricket formats.

📌 Project Overview

The objective of this project is to analyze Virat Kohli's centuries dataset and understand:

Distribution of centuries across formats
Performance trends over the years
Strike rate vs score relationship
Match-winning contributions
Captaincy impact on performance
Statistical measures of batting data
